# Finite vs Infinite Limits

**Finite Domain:** The discrete amino acid backbone and countable immunoglobulin domains. ℱ_n for n < 8. Snapped to RD_TILE_PX=32.

**Infinite Filtration Limit:** The asymptotic boundary where n → ∞, resolving the localized structure into a continuous manifold. ℱ∞.

Finite → discrete, countable, RD-snapped.
Infinite → continuous, manifold, CAM_proj bias.
