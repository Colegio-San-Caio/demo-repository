Verify your download

SHA-256 checksums for the disk images. Put both images and the checksum file in one folder, then run the check.

8a292e7d831e45f4bae09718a15a6b9cd101b13951bbd453f05ea3f177485807 oeneyeOS.img 1b7b350b66f56a4646573de32f7fea22a050cdf99672d8751c49043abc82ebab data.img sha256sum --check checksum.sha256

checksum.sha256

A matching checksum shows the file is the one published here. It doesn't prove the contents are safe.
